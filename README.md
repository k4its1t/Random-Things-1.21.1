# Random Things 0.4.0 — NeoForge 1.21.1 部分移植

这是从本地 `Random-Things` 的 `origin/1.12.2` 分支移植的第一阶段工程。

当前包含：

- 六种木材平台
- 彩虹灯
- 普通木棍块与返回型木棍块
- 沃土及其耕作状态
- 超级滑滑石、超级润滑平台、超级润滑冰
- 灼炎打火石与炽烈火焰（更快更新并以旧版四倍概率点燃相邻方块）
- 瓶装空气（在水下持续使用可恢复空气）
- 稳态末影珍珠（绑定玩家后，掉落约 7 秒将玩家传送到珍珠处）

当前不包含旧版的 Baubles、OpenComputers、JEI、ASM/Coremod、GUI、方块实体、世界生成和复杂传送系统。

## 构建

本工程使用 ARM64 Java 21 和 NeoForge 21.1.250。将 JAVA_HOME 指向自己的 JDK 21 安装目录，然后执行：

```sh
./gradlew build
```

开发客户端和专用服务器分别使用：

```sh
./gradlew runClient
./gradlew runServer
```

旧版参考源码保留在同级目录的 `Random-Things`，没有在本工程中覆盖。

## 验证边界及已知差异

`./gradlew build` 和 NeoForge 游戏测试已通过，测试覆盖返回型木棍块名称与状态、方块掉落、彩虹灯红石变化、平台碰撞、润滑动力学、肥沃泥土植物类型和完整配方内容，以及 Blaze and Steel 点火耐久、瓶装空气与稳态末影珍珠的核心行为。
客户端资源加载和开发专用服务器启动已通过；本机快速连接测试没有形成稳定的自动化连接证据，仍建议在客户端手动加入专用服务器验收。
本轮补齐了 12 个方块掉落表、普通及返回型木棍块配方、透明渲染、工具标签，并修复肥沃泥土的植物更新循环。

- 六种平台采用独立 ID，不支持旧存档迁移。
- 返回型木棍块的物品 ID 为 `randomthings:returningblockofsticks`；放置后会进入返回状态，计时结束后掉落该物品。
- 肥沃泥土通过额外随机 tick 加速已识别的原版植物，并按旧版植物类型恢复耕作状态限制；未知第三方植物交由其自身规则判断。
- Blaze and Steel 现在会放置自定义炽烈火焰；其更新周期、传播、雨水熄灭和 TNT 点燃逻辑已按 1.12.2 规则映射。超润滑石配方仍以超润滑冰替代尚未移植的原料。
- 瓶装空气暂时只在创造模式物品栏提供；旧版海底神殿获取方式需要后续补充战利品表或世界生成逻辑。
- 稳态末影珍珠使用标准 `CUSTOM_DATA` 数据组件保存绑定玩家；离线或未绑定时会保留旧版的附近生物随机传送行为。
- 未实现旧存档数据迁移、客户端自动化连接验收和复杂功能；这些留待后续版本。
- 发布时应标记为实验性部分移植，不能宣称完整兼容旧版行为。
